# QualiCode

QualiCode 是一个面向心理学访谈研究的 AI 辅助质性编码工具。

它帮助研究者把访谈文件转换为可核对的文本，在保留原文证据的基础上，逐步完成开放编码、轴心编码和选择性编码。AI 只提供研究辅助建议，最终判断仍由研究者完成。

## 适合谁

- 心理学和社会科学专业的学生与研究者
- 正在整理访谈材料的研究人员
- 想了解 AI 如何辅助质性研究的开发者

## 核心功能

- 支持 `.docx` 和文字型 `.pdf` 文件
- 上传后先提取文本，再由研究者核对和确认
- 确认后的访谈原文保持锁定，避免分析过程静默改写原文
- 根据连续语义片段生成开放编码建议
- 保留每条编码对应的原文证据、解释和置信度
- 支持接受、修改、删除和手动新增编码
- 基于已确认的开放编码整理轴心类别和关系假设
- 基于已确认的轴心编码提炼核心类别和理论故事线
- 标记无法定位的证据、矛盾证据和需要继续复核的问题
- 在浏览器中导出 Markdown 和 JSON 结果
- 支持同一标签页刷新后恢复当前研究会话

## 使用流程

```text
上传访谈文件
    ↓
核对并确认文本
    ↓
生成开放编码建议
    ↓
研究者接受、修改或删除编码
    ↓
确认开放编码
    ↓
整理轴心类别与关系
    ↓
确认轴心编码
    ↓
生成选择性编码与理论故事线
    ↓
导出结果
```

## 本地运行

```bash
npm install
npm run dev
```

然后打开 `http://localhost:3000`。

如果需要使用 AI 分析，请在项目根目录创建 `.env.local`：

```bash
DEEPSEEK_API_KEY=your-server-side-key
DEEPSEEK_MODEL=deepseek-chat
QUALICODE_ACCESS_CODE=optional-shared-code
```

未配置 `DEEPSEEK_API_KEY` 时，仍可以体验文件读取、文本核对和结果导出流程，但 AI 分析功能不可用。

## 隐私与研究边界

- 请只上传已经脱敏的访谈材料，不要上传真实姓名、联系方式、身份证件、病历或其他可识别个人身份的信息。
- 项目本身不建立业务数据库，也不长期保存上传文件、访谈原文或分析结果。
- 浏览器会话保存在当前标签页的 `sessionStorage` 中，关闭标签页后不会跨设备恢复。
- 使用 AI 分析时，访谈文本会发送给服务端配置的 DeepSeek API。请在使用前确认符合你的研究伦理、机构规定和数据管理要求。
- AI 输出是研究辅助建议，不是经过验证的因果结论，也不能替代研究者的编码判断。
- 导出的文件可能包含访谈原文，请妥善加密、保存和删除。

## 当前限制

- 暂不支持扫描版 PDF 的 OCR
- 暂不支持 `.doc` 文件
- 暂不支持录音转写、多文件项目和跨设备同步
- AI 生成的编码和关系需要研究者逐条核对
